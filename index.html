Sync phone & laptop

Uses a private GitHub Gist so both devices share the same plan. Your token stays in this browser only — it’s never uploaded into the meal plan file.

  1. On GitHub, create a classic token with the gist scope: Create token
  2. Paste it below on this device, then tap Save & sync.
  3. On your other device, open this same site, paste the same token, and the same Gist ID (shown after the first sync).
